# Editor compatibility runtime

The current product server loads its editor and shared model from `dist/`. Start the application from the repository root with `npm start`; do not serve this directory as a separate product.

The earlier standalone prototype's release archives, source manifests, preparation scripts and duplicate project media are excluded. The current product has its own curated example media in `product/web/examples/`. The editor's required styles, scripts, fonts and allowed image assets are retained here.
