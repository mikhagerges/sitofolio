# الجولة 01 — البداية وأول استخدام

التاريخ: 16 أكتوبر 2026. الحالة: **تم التحقق الوظيفي؛ بانتظار الاعتماد البصري من ميخا**.

## نطاق الجولة

التسجيل بالبريد، التخصص والهدف، الشخصية البصرية، البيانات الأساسية، إضافة العمل اختياريًا، الاقتراحات، والوصول للمحرر. لم نعد تصميم الداشبورد، ولم ننشر شيئًا أو نعدّل محتوى حساب المستخدم. التعديلات الصغيرة على روابط الاستيراد والقوالب والبروفايل لازمة لاستمرار الرحلة والاحتفاظ بالاختيارات.

## الرحلة الحالية

1. **Your work:** اختيار تخصص واحد وهدف واحد.
2. **Your style:** ست بطاقات مصوّرة؛ اختيار واحدة أو اثنتين؛ منع الثالثة مع رسالة واضحة ودعم الكيبورد.
3. **Your profile:** اسم ومسمى مطلوبان، نبذة وموقع اختياريان داخل تفاصيل مطوية؛ يمكن إضافة الصورة والروابط داخل المحرر لاحقًا.
4. **Add work:** دخول مسار الاستيراد الحالي أو Skip for now. يمكن العودة للإعداد أثناء الاستيراد، ولا يُقال إن المهمة اكتملت قبل مراجعتها.
5. **Your template:** ثلاثة اقتراحات، معاينة من دون تطبيق، عرض الجميع، ثم اختيار القالب والدخول للمحرر.

الأمثلة تحمل اسم وأعمال ميخا لأغراض العرض، مع توضيح ذلك. اختيار القالب في الإعداد لا ينسخ الأمثلة تلقائيًا، ولا يضع صورة ميخا أو مشاريعه داخل حساب جديد. الحفظ والنشر يظلان منفصلين.

## دليل التحقق

| السيناريو | النتيجة |
|---|---|
| تسجيل حساب جديد في مساحة QA منفصلة | صفر مشاريع، وصورة شخصية فارغة؛ دخل الإعداد |
| محاولة الاستمرار دون تخصص أو هدف | منعتها قيود النموذج |
| محاولة الاستمرار دون شخصية بصرية، أو اختيار ثالثة | ظهرت رسالة، ولم يُسمح بتجاوز الحد |
| اختيار Experimental بمفتاح Space | عمل الاختيار وتحدث العداد |
| تحديث الصفحة، الرجوع بين الخطوات، وتأجيل ثم الخروج والدخول | احتُفظ بالتخصص والهدف والشخصية والبيانات المطلوبة |
| ترك النبذة والموقع والصورة والعمل فارغة | أمكن متابعة الرحلة والوصول للمحرر |
| معاينة قالب ثم الرجوع | بقيت الرحلة، وظلت أمثلة المشاريع غير محددة للنسخ افتراضيًا |
| View all templates ثم العودة | ظهرت 20 بطاقة، ثم عادت الاقتراحات الثلاثة |
| Use Mosaic على حساب الاختبار | فتح المحرر باسم الحساب ومسمّاه، بلا صورة أو مشاريع ميخا |
| إيقاف خادم QA أثناء حفظ اختيارات الشخصية ثم إعادة تشغيله | احتُفظ بالخيارين وبنفس المرحلة، وعملت إعادة المحاولة |
| 1280px و768px و390px، فاتح وداكن | لا تمرير أفقي؛ صور الاختيارات ظاهرة؛ Continue متاح أثناء التمرير |
| اختبارات Node | 32 اختبارًا ناجحًا: الستة الخاصة بقواعد الإعداد، اختبار تكامل رحلة كاملة، والـ25 السابقة |

اختبارات المتصفح استخدمت http://localhost:4190 وبيانات QA تحت data/onboarding-review؛ الحسابات على http://127.0.0.1:4180 لم تُبدل أو تُعدل. جرى تشغيل خادم المنتج والـworker المحليين عند اكتشاف توقفهما.

## ما لم نعتمده في هذه الجولة

- لم يُغلق الاعتماد البصري؛ ميخا يقيّم وضوح الخطوات وشكل الاختيارات والاقتراحات.
- لم نختبر Google الحقيقي أو استعادة البريد أو إرسال البريد؛ هذه تحتاج خدمات حية وتراجع في القسم 11.
- مسار الاستيراد نفسه، جودة AI، جميع القوالب والمحرر وكل متصفحات السوق ليست معتمدة بهذه الجولة؛ لها أقسام مستقلة.
- لا توجد هجرة إجبارية لحسابات قديمة؛ الحساب الجديد يبدأ الرحلة تلقائيًا، ويمكن فتح /#start/1 لبدء الإعداد يدويًا.
- هذه النتيجة لا تعني جاهزية الإطلاق العام.
