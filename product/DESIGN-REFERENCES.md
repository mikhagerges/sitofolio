# Editable portfolio directions · 9 October 2026

## Interface and motion direction · 16 October 2026

The new SitoFolio interface uses the owner's seven supplied references to develop an original type-led composition, a switchable live mood preview, public catalog browsing, and clearer studio navigation. The first portfolio motion pass covers Noir, Solstice and Signal, with chapter navigation for project stories. See [round 02](reviews/02-INTERFACE-DIRECTION.md) for the reference-to-decision mapping, verified scope and remaining visual review. The existing 20-template catalog below remains intact.

SitoFolio now contains 20 templates: 14 new compositions and the six existing starters. All use SitoFolio's own renderer, bundled example artwork and editable workspace data. Reference sites informed layout, hierarchy and atmosphere; their site code, photographs and project artwork were not copied.

The earlier Aire, Folio, Signal, Afterhours, Exhibit and Studio templates remain available under Essentials. Every template contains a home page, work index and three fictional seven-block case-study examples. Examples may be included once, within the account's project limit, as Draft/Private projects. Real account names and existing project content are preserved.

The gallery supports search, visual filters, desktop/mobile examples and a temporary “My content” preview. Trying a template does not save it. “Start editing” applies the layout and opens the simplified editor. Clicking an editable preview element selects its property panel without a popup. Advanced controls remain available.

Local validation: 23 passing integration/security tests; desktop checks for all 14 new directions; 390px checks for all 14, with no horizontal document overflow; gallery search/filter checks; actual title edit/save/preview; project image selection from the guided editor. External provider integrations still require accounts and live verification, as described in DELIVERY-STATUS.md.
